# Game of Thrones Analytics Dashboard

Интерактивная лабораторная работа №10 по книжному датасету персонажей **A Song of Ice and Fire**. Проект работает локально: откройте `dashboard_10/index.html` двойным щелчком. Интернет и сервер для просмотра не нужны. Панель использует `dashboard_10/data/characters.js`, созданный из обработанного CSV.

## Состав

- `dashboard_10/index.html`, `style.css`, `script.js` — интерфейс и визуализации без внешних библиотек.
- `dashboard_10/data/character-deaths.csv` — оригинальный файл, 917 строк.
- `dashboard_10/data/character-deaths-cleaned.csv` — обработанный файл, 917 строк.
- `dashboard_10/data/characters.js` — данные для запуска через `file://`.
- `dashboard_10/data/quality-report.json` — проверка структуры и качества данных.
- `dashboard_10/prepare_data.py` — воспроизводимая очистка.
- `screenshots/` — реальные снимки браузера при 1920 × 1080.
- `Лабораторная работа 10.docx` — отчёт.

## Повторная подготовка данных

Установите Python 3.10+ и выполните в корне проекта:

```powershell
python -m pip install -r requirements.txt
python dashboard_10/prepare_data.py
```

Скрипт проверяет ожидаемые столбцы и двоичные признаки, убирает точные дубликаты, приводит числа к целочисленным типам с возможными пропусками, нормализует написание домов и создаёт вычисляемые поля. Пропущенные значения года и книги смерти не заменяются вымышленными датами. `None`, `Night's Watch` и `Wildling` в поле «House» отражают категории исходного столбца, а не дома.

## Интерфейс

Фильтры по книге смерти, году смерти, нескольким домам, полу, знатности и наличию года связаны каскадно. Обновляются четыре KPI, пять графиков и таблица. В таблице доступны поиск, сортировка и страницы. Книги обозначены исходными номерами 1–5; годы 297–300 принадлежат книжной хронологии и не соответствуют сезонам телесериала.

## Данные и права

Источник: [TheMLGuy/Game-of-Thrones-Dataset](https://github.com/TheMLGuy/Game-of-Thrones-Dataset), файл `character-deaths.csv` в ветке `master`. Согласно описанию репозитория, набор о смертях подготовлен Erin Pierce и Ben Kahle для анализа выживаемости персонажей. На момент подготовки проекта в исходном репозитории не обнаружен отдельный файл лицензии; поэтому MIT-лицензия этого проекта распространяется только на созданный здесь код и документацию, не на исходные данные. При дальнейшем распространении исходного CSV проверьте права у правообладателей данных.

## Результаты

Исходный файл содержит 917 строк и 13 столбцов, точных дубликатов нет. Известны год смерти у 305 персонажей и книга смерти у 307. Больше всего записей о смерти относится к книге 3, *A Storm of Swords* (97). Подробности и проверки — в `TESTING.md`.
